Flexible PCB Bending

This FPC is from https://github.com/iotengineer22/ghost-sticker/
Let’s bend it
Select File → Board Setup
Go to Board Stackup → Board Editor Layers
Create a layer named “freekicad” (case insensitive)
Select the freekicad layer
Draw a bend line
Add a text object with the bend settings
Move (M) the text and attach it to the bend line
Open it in FreeCAD
Voilà!
You can adjust the bend settings in FreeCAD
Keep in mind that reloading restores the bend settings from the KiCad file
Enabling more layers slows things down, so you may want to enable them last
